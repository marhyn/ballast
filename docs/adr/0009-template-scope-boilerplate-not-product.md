# Template scope: boilerplate pages ship for real, product pages don't

Auth flows (sign-in/up/reset), organization management (switch/settings/invite), billing/subscription management, and admin tooling (org/user/subscription oversight, gated behind a `platformAdmin` check, not a separate app per ADR-0006) are built into this template for real — they're identical in shape across nearly every B2B SaaS, so pre-building them saves genuine time and there's no product-specific decision buried in them. Marketing/landing pages, pricing narrative, and product-specific dashboard views are deliberately left out of the template: every real project rewrites these anyway, so placeholder content here would just get deleted, and risks worse — misleading an agent into treating throwaway copy as the pattern to follow. Those get built per-project via the `design-a-page` skill once there's an actual product to design for; the `bootstrap-project` skill (run once when a project starts from this template) captures that product context first.
